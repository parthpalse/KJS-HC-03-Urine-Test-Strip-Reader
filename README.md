# KJS-HC-03 Urine Test Strip Reader using Colorimetry

Point-of-Care (PoC) diagnostic backend application developed using Node.js and Express.js for the Web Programming Laboratory (WPL).

## Features
- **Node.js HTTP Server & Custom Routing**: Native HTTP handling with HTML and JSON payloads.
- **Asynchronous Sensor Callback**: Real-time optical dipstick sensor reading simulation.
- **Synchronous & Asynchronous File Operations**: Medical test record persistence using Node.js `fs` and `fs.promises`.
- **Custom Mathematical Module**: Concentration interpolation and colorimetric analysis.
- **Express.js Architecture**: REST endpoints, static middleware (`express.static`), and dynamic server-rendered reporting using EJS.
